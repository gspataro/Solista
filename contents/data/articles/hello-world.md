Welcome to your first article built with **Solista**.

If you're reading this page, it means you've already done something important: you've successfully built a working static website from scratch.

## 🚀 What is Solista?

Solista is a static site builder designed to be:

- simple to use
- fast during builds
- flexible in content management

Unlike many other tools, your content lives in **real files**, making it easy to read, edit, and version.

## ✍️ Writing content

Content is written in Markdown, just like this file.
You can define metadata using frontmatter:

```yaml
title: "Title"
date: 2026-03-17
categories:
    - draft
```

This allows Solista to automatically organize:

- posts
- archives
- relationships between content

## 🧑‍💻 The place for developers

If you need to write some technical stuff, [Tempest Highlighter](https://tempestphp.com/3.x/packages/highlight) is here to help too:

```php

```

## 🔗 Internal links

You can easily link to other content within your site.

For example:

👉 Read also [the second post](orchestra://articles/second-post.md)

Solista will automatically resolve this into the correct permalink.

## 🗂️ Categories

This article belongs to the **News** category.

Categories allow you to create automatic archives and better organize your content.

## ⚡ Performance

During development, Solista uses an advanced caching system to keep builds extremely fast.

In production, the result is a static site that is:

- fast
- secure
- easy to deploy
